# Project Language Policy

Effective July 28, 2026, English is the required language for all new
ProofLayer project work.

This includes:

- Source code, identifiers, comments, and user-facing strings
- File and directory names
- Technical and product documentation
- Architecture Decision Records (ADRs)
- Issues, pull requests, reviews, and commit messages
- Test names, fixtures, release notes, and changelogs
- Product, demo, sales, and investor materials

The founders may continue day-to-day conversation in Turkish. Existing Turkish
documents may remain unchanged until they are revised or explicitly scheduled
for translation. Any new document or material must be written in English.
