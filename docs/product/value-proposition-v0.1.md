# MVP Value Proposition v0.1

**Frozen:** August 5, 2026

> ProofLayer continuously proves whether a safe endpoint signal reaches Splunk
> with the fields needed for detection—and pinpoints the first broken stage.

## Current proof behind the statement

- One safe Windows process-marker behavior
- Exact canonical correlation from Sysmon to Splunk
- Required-field presence validation
- Three repeatable runs with measured ingestion latency
- Minimum-permission Splunk observation

Detection and alert validation are product requirements but are not yet part of
the completed technical proof.
